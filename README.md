## What I'm working on

**Skill Taxonomy @InfoEdge** — 31k+ raw skill strings standardized into a canonical taxonomy. A three-layer auditor (exact → fuzzy → vector similarity) sits on top of Birch-clustered candidates, so we get high recall without burning tokens per cell. SQLite-backed state machine + human-in-the-loop gates make the pipeline resumable from any failure point.

**Business impact:** one canonical taxonomy means downstream search, matching, and recommendations stop disagreeing — cleaner data for every team that touches skills.


**Self-healing onboarding pipeline** — end-to-end LLM pipeline driving Playwright headless browsers to onboard career pages. Validation loops catch drift mid-flow instead of after.

**Business impact:** **~96% reduction in manual setup time**, freeing ~60+ person-days/month of engineering and ops effort.

## How I think

- **Product-first engineering.** Start from the user's workflow; the system fits it. Not the other way around.
- **LLMs are amplifiers, not magic.** Wrap them in state machines, validation loops, and audit layers - then you get reliability instead of vibes.
- **Ship, then harden.** MVP in days, resumability + human-in-loop gates in the weeks after.
- **Cost is a feature.** Token spend, infra spend, and human time are all on the same spreadsheet.
